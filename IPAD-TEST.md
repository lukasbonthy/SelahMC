# SelahMC v8.3.3 iPad test

This branch creates a private GitHub Codespace test server automatically.
It downloads the currently deployed SelahMC v8.3.2 client, applies the exact
v8.3.3 direct texture-registration hotfix, verifies the five critical SHA-256
checksums, and forwards port 8000.

[Open the v8.3.3 test in GitHub Codespaces](https://codespaces.new/lukasbonthy/SelahMC/tree/ipad-v8.3.3-test?quickstart=1)

The `main` branch and the production SelahMC deployment are not modified.
